- Exposed only a minimal subset of astrological findings (primarily D1, basic D9/D10 summaries).

## 6. Data Consistency & PDF QA Validation

### 6.1 Pre-Generation Consistency Validator (`validateReportDataConsistency`)
Before any TeX generation or compilation begins, the engine runs strict invariant assertions:
1. **D1 Planetary Register Identity:** Every planet in the register matches the D1 chart degrees and signs.
2. **D10 Dashamsha Identity:** D10 Ascendant and 10th house match the calculated D10 Varga chart.
3. **Shadbala Totals:** Sthana, Dig, Kala, Cheshta, Naisargika, and Drik sum to total Virupas and match Rupas conversion (`Rupas = Shashtiamsas / 60`).
4. **Ashtakavarga Invariants:** Sarvashtakavarga totals match the classical 337 sum.
5. **Dasha Timeline Consistency:** Vimshottari Dasha starts with the native's verified birth Mahadasha and conforms to the natal Moon nakshatra ruler.

### 6.2 Post-Compilation PDF QA Validator (`PdfQaValidator`)
- Verifies `%PDF-` magic header and valid `%%EOF` marker.
- Verifies page count meets or exceeds the required threshold.
- Scans compiled output and raw TeX payload for forbidden placeholders (`'Valued Client'`, `'Not supplied'`, `'Personalized interpretation unavailable'`, `'undefined'`, `'null'`, `'Lorem ipsum'`).
